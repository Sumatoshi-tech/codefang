# Code of conduct

Codefang adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. By participating in this project, you agree to uphold it.

## Read the full text

The complete, canonical code of conduct lives on the documentation site:

**<https://sumatoshi-tech.github.io/codefang/contributing/code-of-conduct/>**

The source for that page is
[`site/contributing/code-of-conduct.md`](site/contributing/code-of-conduct.md),
which is the canonical version. Edit it there.

## Reporting and enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be
reported **privately** to the maintainer at **<d.y.gaevskiy@gmail.com>**. Do not
open a public GitHub issue, discussion, or pull request to report a violation —
a private report protects everyone involved while the matter is reviewed.

All complaints will be reviewed and investigated promptly and fairly, and the
maintainer will respect the privacy and security of the reporter.
