# Support

Stuck, confused, or pretty sure you found a bug? You're in the right place. This
page sends you to the right door so nothing gets lost and the maintainer's inbox
doesn't turn into one big undifferentiated pile.

**GitHub Discussions is not enabled** for this project. Everything routes through
GitHub Issues or the security channel below—pick the one that matches what you have.

## I have a question or need usage help

Open a [GitHub issue](https://github.com/Sumatoshi-tech/codefang/issues/new) and add
the `question` label. Use this for "how do I...", "is this the right command for...",
or "why does Codefang do X" questions.

Before you open it, a quick win: skim the
[documentation](https://sumatoshi-tech.github.io/codefang/), which covers the
analyzers, the `uast` / `codefang` split, and the common workflows. Your answer may
already be flexing there.

## I found a bug

Open a [GitHub issue](https://github.com/Sumatoshi-tech/codefang/issues/new) using
the **bug report** template. Tell us what you expected, what actually happened, the
steps to reproduce, and your environment (Codefang version, OS, Go version). The more
we can reproduce, the faster we can fix.

## I found a security vulnerability

**Do not open a public issue.** Security holes go through the private channel so we
can patch before they get weaponized. See [SECURITY.md](SECURITY.md) for the full
drill—it routes you to GitHub's private vulnerability reporting (Security Advisories),
not the public Issues tracker.

## What to expect

This project is maintained on a best-effort basis. We triage questions and bug reports
as time allows, and we prioritize reproducible reports. Be kind, be patient, and bring
details—that's how the dumbbells get racked.
